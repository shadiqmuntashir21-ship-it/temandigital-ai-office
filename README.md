# Teman Digital AI Office

Kantor AI internal untuk operasional Teman Digital.

## Stack
- Next.js + TypeScript
- Supabase (PostgreSQL, Auth, Storage, Realtime, RLS)
- Gemini melalui server-side provider layer
- React Three Fiber / Three.js (fase 3D)

## Prinsip
- UI Bahasa Indonesia
- 3D untuk experience/navigasi, dashboard 2D untuk produktivitas
- AI Developer hanya untuk owner
- Semua tindakan kritis melalui Approval Center
- Secret tidak boleh disimpan di source code
